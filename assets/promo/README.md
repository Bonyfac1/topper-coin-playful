# Promo assets

High-quality, full-fidelity media for off-site sharing. **Not** uploaded by
`deploy.sh` (would bloat the website); the website uses smaller optimized
copies in `assets/`.

## Files

- **`mascot-full.mp4`** — 5 s, 1024×1024, ~5 MB, with synthwave audio.
  Generated via Kling 3.0 (higgsfield) from `assets/mascot.webp` as the
  start frame. Use this on Twitter/X, Telegram, Discord, Instagram —
  platforms that re-encode anyway, so you want to give them maximum
  source quality.

For the size-optimized hero loop the website ships, see
`assets/mascot.mp4` in the project root.
